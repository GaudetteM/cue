# Cue

A simple goal tracker for staying focused on what matters today.

No complicated project management. No endless lists of tasks. Just a clear view of what's on your cue.

## Features

### Goals

Create goals and move them through three simple states:

**Todo → Doing → Done**

Goals can be edited or deleted at any time.

### Categories

Items can be organized into four categories:

- Reminder
- Goal
- Task
- Other

### Recurring items

Items can repeat on a schedule:

- Daily
- Weekly
- Monthly
- Specific days of the week
- Specific days of the month

Weekly goals can be assigned to any combination of days.

For example:

```ts
recurrence: 'weekly'
recurrenceDays: [1, 3, 5]
